# C++ Task Tracker CLI
A simple, terminal-based Task Management application built in C++.
## Features
- 📝 Add new tasks - 📋 View task list with status flags ([DONE] / [PENDING]) - ✔️ Mark tasks as completed - 
🗑️ Delete tasks with automatic ID re-indexing
